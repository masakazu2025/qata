# セッションの終わり

1. 関門を通す。テストや検査があるリポジトリでは、すべて通ることを確かめる。通らなければ、通るまで直すか、手を入れる前の状態に戻す。
2. このセッションで自分で決めたことを、`docs/decisions.md` の上に足す（決めた人：AI、レビュー：未）。
3. 途中で出てきた、別の直したいものを `docs/ideas.md` に書く。
4. `docs/log.md` のいちばん上に「日付：どこまでやったか。次は何か」を一行足す。
5. 人への報告では、レビューしてほしいもの（「レビュー：未」で今回足したもの）と、人に聞くこと（あれば）だけを伝える。質問の出し方は `.claude/rules/general/autonomy.md` に従う。
