# セッションの始め

1. `docs/log.md` のいちばん上の行を読み、前回どこまでやったか、次は何かをつかむ。
2. `docs/scope.md` を読み、今回やること・やらないことを確かめる。
3. `docs/decisions.md` のうち「レビュー：未」のものに目を通す。人のレビューで変わったものがあれば、それに従う。
4. 今回のセッションでやる一歩を一つに決める。テストが通る状態で終われる大きさにする。
5. やる一歩を、人に一行で伝えてから始める。
