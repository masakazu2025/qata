# セッションの始め

1. ボード（場所はプロジェクトの CLAUDE.md）の Next の列を `gh` で見る。上から、担当が人でない issue を一つ選び、今回やるものにする。担当が人のものは、把握だけする。
2. その issue の本文とコメントを読み、終わりの条件を確かめる。
3. そのリポジトリで最近マージされた pull request を数件見て、直近にやったことをつかむ。
4. `docs/scope.md` を読み、今回やること・やらないことを確かめる。
5. `docs/decisions.md` のうち「レビュー：未」のものに目を通す。人のレビューで変わったものがあれば、それに従う。
6. issue が一つのセッションで終わらない大きさなら、sub-issue に分けてから、上の一つをやる。
7. 今回やる issue を人に一行で伝え、In progress にしてから始める。
8. そのあとは `work-issue` の 2（要件の確認）から進める。
