# セッションの始め

1. `docs/tasks.md` を読み、「次にやること」のいちばん上のタスクを今回やるものにする。人の判断待ちで止まっているものがあれば、それも把握する。
2. `docs/log.md` の上の数行を読み、直近にやったことをつかむ。
3. `docs/scope.md` を読み、今回やること・やらないことを確かめる。
4. `docs/decisions.md` のうち「レビュー：未」のものに目を通す。人のレビューで変わったものがあれば、それに従う。
5. タスクが一つのセッションで終わらない大きさなら、分けて `docs/tasks.md` に書き直してから、上の一つをやる。
6. 今回やるタスクを、人に一行で伝えてから始める。
