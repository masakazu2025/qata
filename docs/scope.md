# 今回のスコープ（PoC）

## デモの完了条件

**Windows の電卓に対して、日本語の手順から、操作の自動実行、結果のスクショ表示まで、一本通るデモができること。**

技術を知らない人に「こういうことができる」と見せられることが目的です。

## やる

- 自然言語の手順と確認事項 → テストケースの生成
  - 生成は AI（PoC では Claude）が、MCP 経由で server の道具を使って行う
  - server は LLM を呼ばない
- 生成されたテストケースの検証と登録
  - server の関門（形式の検証、部品の辞書との照合）を必ず通す
- テストケースの確認と管理（web）
  - 人が確認するかどうかは、チェックボックスで選べる
- テストの実行（操作はキー押下とタッチのみ）
- 結果とスクショの閲覧
- 画面の部品の辞書（部品の名前 → 座標やキー）。手書きでよい
- 確認事項は 1 種類だけ（例：画面に指定の文字列が出ているか）

## やらない

- テストの自動修正
- ログの自動採取、報告の自動記載
- 部品の辞書の自動作成
- 状態遷移・レイアウト確認・探索的テストなど、手順と確認事項以外のテスト手法
- 会社の環境（Microsoft 365 Copilot など）との接続
- server の中から LLM を呼ぶ仕組み（web 画面から日本語でテストを作る入口）
- ルール（rules）を AI が自分で見直して改善する仕組み

「やらない」にあるものに備えた抽象化・フォルダ・コードは作りません。思いついたことは [ideas.md](ideas.md) に書きます。
