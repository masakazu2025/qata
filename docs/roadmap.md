# 中期目標

[vision.md](vision.md) の目標に向かう段階を置きます。段階は、期間ではなく、できること（何を見せられたら終わりか）で区切ります（D41）。段階が終わるたびに見直します。いまの段階で作る範囲は [scope.md](scope.md) に置きます。

## 付録：機能の棚卸し

vision の「届いたと言える状態」と「範囲」に届くまでに要る機能です。出どころは [vision.md](vision.md)・[ideas.md](ideas.md)・[use-cases.md](knowledge/use-cases.md)。

- いま：あり／一部／なし
- 頼る先：その機能を作る前に要る機能の番号
