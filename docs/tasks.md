## 次にやること（優先順）

「全部品を偽物でつなぎ、電卓のデモの流れを端から端まで一本通す」（[process.md](process.md) の「順番」の 2）を、境目で分けたもの。終わったら、動くもので人に見てもらう（D21）。

1. **qata-server：MCP の道具を出す**　担当：AI
   - 出す道具が親の `mcp-tools.json` と合うことをテストで確かめる。
2. **qata-runner を偽物で立ち上げる**　担当：AI
   - `POST /runs` で命令を受け、決まった結果と PNG を返す。命令と結果が契約に合うことをテストで確かめる。
3. **qata-web：テストケースの一覧・承認・実行と、結果とスクショの表示**　担当：AI
   - 親の `openapi.yaml` から型を生成する。
4. **端から端まで一本通す**　担当：AI
   - server・偽の runner・web を起動し、MCP で登録 → 実行 → web で結果とスクショを見る、をテストで確かめる。人に画面を見てもらう。
